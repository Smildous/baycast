## Acceptable evidence

Settle YES only if a public Microsoft or Xbox source before close says, in substance, that Microsoft is announcing a new first-party Xbox handheld.

Good evidence includes any one of these:

- An Xbox Wire, Microsoft blog, Xbox.com, or Microsoft newsroom post announcing a handheld Xbox device made by Microsoft or Xbox.
- An official Xbox or Microsoft event video, livestream, or transcript where Microsoft announces the device before close.
- An official Xbox or Microsoft social post before close that clearly announces the device and links to, names, or shows the product.
- A Microsoft press release or official event page that names the device as an Xbox handheld, portable Xbox console, handheld Xbox hardware, or equivalent first-party portable Xbox device.

The wording does not need to use exactly `handheld`. It is enough if the official source describes a portable, self-contained Xbox gaming device from Microsoft or Xbox. The evidence must be an announcement, not only a rumor acknowledgement.

Record the source URL, publication timestamp, archived URL if available, and the exact quote used for settlement.

## Unacceptable evidence

Do not settle YES from any of these alone:

- Leaks, rumors, unnamed sources, datamining, retail placeholders, patent filings, supply chain reports, or analyst notes.
- A journalist's claim that Microsoft plans to announce, is expected to announce, or has internally discussed a handheld.
- Forecast markets, prediction pages, probabilities, vote counts, comments, or screenshots of Baycast activity.
- Generic Xbox app, Game Pass, Windows handheld mode, cloud gaming, controller, accessory, or partner PC news without a new Microsoft first-party Xbox handheld announcement.
- ASUS ROG Xbox Ally or another partner-built handheld unless the official source clearly says Microsoft itself is announcing a new first-party Xbox handheld. Co-branded partner hardware is not enough by default.
- A statement after close saying an announcement happened before close unless the post-close statement points to a public pre-close official source.
- Private briefings, embargoed press material, deleted posts with no reliable public archive, or inaccessible material that cannot be verified publicly.

## Edge cases

- If Microsoft announces development of a first-party Xbox handheld without price, date, or specs, that can still be YES if the official wording is clear enough that a new device exists.
- If Microsoft says it is `exploring`, `considering`, `researching`, or `working on prototypes`, that is not enough unless it is presented as an announcement of a product.
- If the source says `next-generation Xbox hardware` but does not identify a handheld or portable device, do not count it.
- If the device runs Windows but is branded and announced by Microsoft or Xbox as Xbox handheld hardware, count it.
- If the only pre-close item is a teaser, count it only when the teaser clearly announces the handheld. A vague silhouette, countdown, or `future of Xbox` teaser is not enough.
- If an official post is edited after close, use the pre-close archived version or another reliable timestamped official record. Do not rely on post-close edits for YES.
- If time zone labels conflict, convert the publication time to UTC and document the conversion.
