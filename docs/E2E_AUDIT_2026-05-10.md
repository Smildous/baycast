## Bugs Found

### 🐛 BUG-1: Sitemap missing `/how-it-works` URL
- **Severity:** Medium (SEO impact)
- **Description:** The How It Works page is not included in `/sitemap.xml`. This page is a key SEO asset with rich content about the Blind Consensus Protocol.
- **Expected:** `<loc>https://baycast-p.vercel.app/how-it-works</loc>` should be in the sitemap
- **Actual:** Only 6 URLs present, `/how-it-works` not among them

### 🐛 BUG-2: Sitemap missing individual question URLs
- **Severity:** Medium (SEO impact)
- **Description:** Commit e2a03c5 was intended to add question URLs to the sitemap, but no `/questions/{uuid}` entries exist. Only the `/questions` index page is listed.
- **Expected:** Each of the 10 live questions should have an entry like `<loc>https://baycast-p.vercel.app/questions/d451ce46-...</loc>`
- **Actual:** Zero question-specific URLs in sitemap

### ℹ️ NOTE-1: Questions pagination not visible
- **Severity:** Low (informational)
- **Description:** No pagination controls visible on `/questions`. With 10 questions this is fine, but will be needed as the platform scales.

### ℹ️ NOTE-2: Onboarding Step 2 not testable
- **Severity:** N/A
- **Description:** Commit 5a45dc2 (Onboarding Step 2 interactive demo) requires an authenticated user session. Could not verify in unauthenticated E2E audit.

## Recommendations

1. **Fix sitemap.xml** — Add `/how-it-works` and all individual question URLs. This is the most impactful SEO fix.
2. **Add pagination to /questions** — Prepare for scale.
3. **Test onboarding flow** — Commit 5a45dc2 should be verified with an authenticated test account.
4. **Consider adding structured data** — JSON-LD for FAQ and HowTo schemas on `/how-it-works` would boost SEO.
5. **Add canonical URLs** — Not observed on any page. Adding `<link rel="canonical">` would prevent duplicate content issues.

## Conclusion

Baycast prototype is in **excellent shape**. All 7 pages load without errors, CTAs work correctly, SEO meta tags are well-crafted, and the recent features (BCP content, leaderboard empty state, auth titles, OG images, landing optimization) are all verified working. The only significant gap is the **sitemap** which is missing the How It Works page and individual question URLs — this should be prioritized for the next deploy.
