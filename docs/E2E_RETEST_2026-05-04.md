## Issues Found

### BUG-001: Category filters return no results (AQ-027 regression persists)
- **Severity:** HIGH
- **File:** `app/questions/page.tsx:68`
- **Description:** `query.ilike('category', normalizedCategory)` does not return matching questions. All category filters (Technology, Economy, Science, etc.) show "No questions in this category" despite questions existing in those categories on the homepage.
- **Fix applied:** Changed `ilike` to `eq` — categories are already normalized via `normalizeCategory()`, so exact match is correct.
- **Status:** Fix committed locally, needs deployment.

### BUG-002: No mobile navigation menu
- **Severity:** HIGH
- **File:** `components/NavClient.tsx:53`
- **Description:** Navigation links are hidden on mobile (`hidden md:flex`) with no hamburger menu alternative. Mobile users can only see the BAYCAST logo and "Get Started" button — no way to reach Questions, Blocks, or Leaderboard.
- **Fix needed:** Add a hamburger menu button (visible `md:hidden`) that toggles a mobile slide-down/drawer with NAV_LINKS.
- **Status:** Not yet fixed — requires UI component work.

### BUG-003: Resolution source URL is malformed
- **Severity:** LOW
- **File:** Question detail page (data issue)
- **Description:** On the Bitcoin question, the resolution source link is `https://CoinGecko` (not `https://coingecko.com`). This appears to be a data issue in the DB, not a code bug.
- **Status:** Data fix needed in DB.
