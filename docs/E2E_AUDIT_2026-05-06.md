## UX Observations & Recommendations

### Positive Changes Since May 5
- No regressions detected
- All core pages remain stable and functional
- Footer consistently present across all routes
- Empty states on leaderboard and blocks remain well-designed

### Outstanding Issues (Priority Order)

1. **🔴 Fix category filters (AQ-027)** — This is a core navigation feature. Users literally cannot filter by topic. The Sprint 5 recommendation to debug `normalizeCategory()` and run a DB migration remains the correct approach. This should be the #1 priority.

2. **🔴 Fix onboarding modal (AQ-028)** — The modal still blocks all content on first visit and cannot be dismissed with Escape. Sprint 5 recommended: (a) add Escape key listener, (b) add backdrop click handler, (c) optionally delay by 3 seconds or move to signup flow. The Escape key dismiss was specifically requested and still missing.

3. **🟡 Add search to questions page (AQ-029)** — With category filters broken AND no search, question discovery is limited to scrolling through the full list. Even a simple text search with debounce would help.

4. **🟢 Sprint 5 backlog items still pending:**
   - MIN-01: Sorting dropdown (Deadline, Popular, Newest)
   - MIN-02: Filter group labels ("Category", "Status")
   - MIN-03: Hide "Blocks" nav or show "Coming Soon"
   - MIN-06: Focus-visible rings on interactive elements
   - MIN-08: Show "—" instead of "0" for empty consensus
